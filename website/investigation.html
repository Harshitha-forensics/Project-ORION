Case Overview

Case reference: DDW-104-A07

This educational case demonstrates how available web-server logs and local file artifacts can be examined together.

Evidence Sources

  • NGINX access logs: recorded HTTP requests and timestamps.
  • Download-folder examination: whether a named file is present in the checked location.
  • SHA-256: a hash used to check whether evidence files have changed.

Investigation Workflow

  1. Preserve and examine available logs.
  2. Identify relevant search and download requests.
  3. Compare timestamps with available local file artifacts.
  4. Document observations and limitations.

Important Limitation

A missing file in a checked folder does not prove secure deletion. Server logs do not establish a visitor's real-world identity or defeat Tor anonymity. Findings must be interpreted alongside other evidence.
