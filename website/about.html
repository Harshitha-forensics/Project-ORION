About Project ORION

Observe. Record. Investigate. Understand.

What is ORION?

Project ORION is an educational digital-forensics demonstration that explores how web-server logs, file metadata, timestamps, and cryptographic hashes can support an investigation.

Visitors can explore sample research records and download an educational evidence package. Investigators can then examine example evidence sources and document their findings.

Project objectives

  • Demonstrate a searchable research archive.
  • Explain how web-server access logs record HTTP requests.
  • Introduce timestamps, file metadata, and SHA-256 hashes.
  • Show how investigators correlate evidence from different sources.
  • Explain the limitations of digital evidence.

Technologies used

Kali Linux Tor NGINX HTML CSS Bash SHA-256

Evidence and limitations

A server access log can show that a resource was requested and record the server's response. It does not, by itself, prove that a visitor saved a file or later deleted it locally.

Claims about local downloads or deletion require relevant evidence from the device or browser. The records in the GitHub demonstration package are educational samples, not evidence from a real criminal investigation.
