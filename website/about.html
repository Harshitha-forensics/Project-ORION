About Project ORION

An educational digital-forensics demonstration.

Project Objective

ORION demonstrates how investigators can examine available web-server logs and correlate recorded HTTP requests with local download-folder artifacts to document a sequence of events.

Technologies Used

  • Kali Linux
  • NGINX web server and access logs
  • Tor onion services for a controlled lab demonstration
  • Bash scripting
  • SHA-256 evidence integrity checks
  • HTML and CSS

What I Learned

  • Examining HTTP access records and timestamps.
  • Correlating evidence from different sources.
  • Checking files and recording their hashes.
  • Documenting findings without overstating what the evidence proves.

Scope and Limitations

ORION is a controlled educational demonstration. A missing file in a checked folder does not prove secure deletion, and server logs alone do not identify a real-world visitor or defeat Tor anonymity.
